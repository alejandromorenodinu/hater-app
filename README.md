# NombreDeTuApp

Aplicación Android de reseñas anónimas cuyo propósito es lo contrario de
lo habitual: **advertir sobre obras de entretenimiento que NO recomendarías**
(películas, series, videojuegos, libros...).

## Sobre el proyecto

Proyecto personal desarrollado durante mi formación en DAMvi (Desarrollo de
Aplicaciones Multiplataforma). Su objetivo principal era aprender a trabajar
con bases de datos NoSQL y a integrarlas en una app Android.

## Qué me ha permitido practicar

- Integración de **Firebase** en un proyecto de Android Studio
- Modelado y consulta de datos en una base de datos **NoSQL**
- Diseño de una app con reseñas anónimas
- Uso de Git y GitHub para el control de versiones

## Tecnologías

- Android Studio
- [Kotlin / Java]
- Firebase ([Firestore / Realtime Database])

## Estado

Proyecto educativo. No está publicado en Google Play.
